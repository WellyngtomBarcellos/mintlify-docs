```shellscript filename
Post: /api/v2/lhama/video/check
```

#### **Authorizations headers**

<ResponseField name="Authorizations" type="string" required>
  Todas as requisições devem incluir sua chave de API no header Authorization usando o formato Bearer `<ambarks-api-key>`. _Sem esse header a requisição será rejeitada_
</ResponseField>

#### **Body**

<ResponseField name="video" type="file" required>
  Nesse campo você enviará o caminho ou arquivo que será analizado.

  Este é o único campo que deve se preocupar -- o **_processamento total será feito em background_**, e não será retornado em webhook.
</ResponseField>

## Respostas

Após sua requisição você poderá ter 2 tipos de respostas, 200 (Sucesso) ou 422 (Não processado)
